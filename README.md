
## Stopwatch Web Application

This project is a responsive and interactive Stopwatch Web Application developed using HTML, CSS, and JavaScript.

## Features

- Start the stopwatch
- Pause the stopwatch
- Reset the stopwatch
- Record multiple lap times
- Accurate time tracking (milliseconds)
- Responsive design
- Modern user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
